# Vue3 UI编码强制规则
1. 全部使用 Vue3 <script setup> 语法，禁止Vue2选项式API、this。
2. UI组件库：使用 shadcn‑vue；输出组件禁止使用已经废弃的props，参考官方最新文档
3. 禁止直接使用原生 <button> <input>，业务表单、按钮全部使用UI库组件。
4. 页面必须具备现代观感：合理padding/margin，卡片圆角8px，柔和阴影，合理留白。
5. 样式尽量用tailwind；配色柔和，禁止高饱和刺眼颜色；颜色、圆角、间距尽量用css变量，不要大量硬编码px、色值。
6. 必须做响应式，适配PC+移动端，不要出现内容溢出。
7. 业务逻辑优先级：功能正确；UI优先级：整洁现代，不要简陋默认样式。
8. 修改已有代码时：**不改动业务逻辑、变量名、事件、接口字段，仅修改视图与样式**。
